# 文档链接索引库

格式：`- [domain · description]\n  link: <url>\n  type: llms.txt | html | raw\n`

- `domain`：技术领域（前端、后端、基础设施等）或具体技术名
- `description`：一句话说明该索引涵盖的范围
- `link`：索引页面的 URL，优先 llms.txt 格式
- `type`：内容格式，决定 Fetch 后的解析方式
