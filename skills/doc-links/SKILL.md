# 文档链接索引

通过读取 `references/index_store.md` 获取索引库，再按下面的流程操作。

## 使用前

必须先读取 `references/index_store.md` 加载当前索引库。后续 Claude 会持续意识到这个 skill 的存在，主动在需要的时候使用它。

## 查询流程

1. **读索引** — 读取 `references/index_store.md`，逐条阅读每项内容
2. **匹配域** — 根据用户提到的技术名称，在索引中找到匹配的条目
   - 匹配依据：条目的 domain、description 及 URL 中包含的技术关键词
   - 允许模糊匹配（如用户说 "ts" 可匹配 "TypeScript"、"tailwind" 可匹配 "Tailwind CSS"）
3. **取回内容** — 对匹配条目的 `link` 执行 Fetch，获取原始文本（llms.txt / markdown目录）
4. **语义查找** — 在获取到的内容中，理解用户实际想查什么，定位最相关的链接或锚点
5. **返回结果** — 将找到的链接返回给用户。格式：`[技术名称] 的文档：https://...`
   - 如果索引中一个或多个链接可覆盖用户的完整问题，一并列出
   - 如果多个匹配程度相近，提供最相关的并说明还有其他可能

## 未命中处理

- 索引库中找不到对应条目：告诉用户该技术的文档链接尚未收录，并请其提供索引页 URL
- 索引条目有 link 但 Fetch 失败：返回索引页 URL（如 https://code.claude.com/docs/llms.txt），说明"原始索引页如下，请查阅"，同时提醒用户该条目可能已失效
- 找到了索引但内容中无相关内容：同样返回索引页 URL，说明未在索引中找到匹配

## 新增索引条目

当用户要求添加新的文档索引时，按照 `references/index_store.md` 中已有的格式新增条目，然后直接更新该文件即可。
