# 情报简报输出格式

本文件定义了情报扫描的输出格式。遵循标准 Markdown 语法，确保在任何 Markdown 渲染器中都能正确显示。

## 格式模板

```markdown
## 情报扫描报告 | MM-DD

### 🔥 紧急情报

**1. [资源/平台名称] — [一句话描述]**

- 来源：[平台]
- 模型信息：[参数量/类型/能力]
- Agent/工具调用能力：[强/中/弱/未知]
- 免费详情：[具体额度，必须包含 tokens/day 或 requests/day]
- 接入方式：[API格式/链接]
- 时效性：[永久] / [限时(截止MM-DD)] / [测试期]
- 推荐行动：[立即注册/持续关注/可以忽略]

**2. [下一个资源]**

...

### 📡 一般动态

- **[平台]** [变动描述] — [影响] [时效性标记]
- **[平台]** [变动描述] — [影响] [时效性标记]

### 📊 已知资源健康

| 平台 | 状态 | 备注 |
|------|------|------|
| NVIDIA NIM | ✅ | 100+ 模型，Step 3.5 Flash 稳定 |
| OpenRouter | ✅ | 25+ 免费模型 |
```

## 无新变化时

```markdown
## 情报扫描报告 | MM-DD

📭 本次扫描未发现新变化

### 📊 已知资源健康

| 平台 | 状态 | 备注 |
|------|------|------|
| NVIDIA NIM | ✅ | 正常运行 |
| OpenRouter | ✅ | 正常运行 |
```

## 格式规则

1. **每段之间用空行分隔**——这是 Markdown 正确渲染的前提，没有空行所有内容会挤成一段
2. **总长度控制在 50 行以内**
3. **紧急情报最多 3 条**，只放真正值得立即行动的
4. **一般动态最多 10 条**，每条用标准 Markdown 列表项
5. **健康表用标准 Markdown 表格**（`|` 分隔）
6. **每条情报标注时效性**：[永久] / [限时] / [测试期] / [需验证]
7. **绝不含废话**——不需要开头寒暄、结尾总结
8. **如果无新变化，如实报告**——不伪造情报

## 评分标签

| 标签 | 含义 |
|------|------|
| 🔥 | 紧急/重磅——新上线强模型、限时免费、重大政策变更 |
| 📡 | 一般动态——额度微调、新模型上线但能力一般 |
| 📊 | 健康快照——已知资源当前状态 |
| ⚠️ | 预警——可能缩水、不稳定 |
| 💀 | 坏消息——免费取消、平台关闭、模型下线 |
| 📭 | 无变化——本次扫描未发现新情报 |
