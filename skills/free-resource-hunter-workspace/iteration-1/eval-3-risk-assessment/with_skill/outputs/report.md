## OpenRouter 风险评估报告 | 2026-05-29

**评估对象**: OpenRouter (openrouter.ai)
**用户需求**: 评估将 agent 工作流切换到 OpenRouter 免费层的可行性和风险
**结论**: **需警惕** — 平台本身靠谱且在快速发展，但免费层对 agent 工作流存在多重限制，不能作为生产环境主方案

---

### 1. 平台存续风险：低

| 指标 | 数据 |
|------|------|
| 成立时间 | 2023 年 |
| 最新融资 | 2026-05-28 $113M Series B（CapitalG 领投，NVIDIA/a16z 参投） |
| 估值 | $1.3B（一年内从 $547M 翻倍） |
| 用户规模 | 8M+ 用户 |
| 周 Token 处理量 | 25T（6 个月内 5 倍增长） |
| 模型数量 | 400+（来自 60+ provider） |

**判断**: 不是小团队或个人项目。Google 母公司 Alphabet 旗下 CapitalG 领投 B 轮，NVIDIA 战略参投，说明机构级资本看好其基础设施定位。短期内倒闭或跑路的风险极低。

---

### 2. 免费层变更历史：已缩水，且趋势明确

**已发生的变更（按时间线）：**

| 时间 | 变更 | 影响 |
|------|------|------|
| 2025-04 | 免费日调用从 200 次降至 50 次（无充值用户） | 纯白嫖用户额度砍 75% |
| 2025-04 | 充值 $10+ 用户日免费调用升至 1,000 次 | 鼓励小额充值，提高门槛 |
| 2025-07 | 两大 provider 转向纯付费；OpenRouter 承担部分免费模型成本 | 免费模型供给端收紧 |
| 2025-07 | 引入 Venice Uncensored 等新免费模型 | 官方主动补充免费供给 |
| 2026-04 | :free 模型从 50+ 降至约 30 个（CostGoat 统计） | 可用免费模型持续减少 |
| 2026-05 | 当前免费模型 27 个（CostGoat 最新统计） | 进一步缩减 |

**趋势判断**: 免费层缩水是**确定性趋势**，不是偶然事件。平台策略从"无差别免费"转向"用 $10 门槛筛选付费用户 + 控制纯免费消耗"。免费模型数量从 50+ 缩至 27 个，且官方明确说了"less popular models will soon transition away from the free tier"。

---

### 3. 免费层对 Agent 工作流的具体限制

**当前免费层限制（无充值）:**
- 50 次/天（所有免费模型共享，不是每个模型 50 次）
- 20 RPM（每分钟请求数）
- 无 SLA，无可用性保证

**充值 $10 后:**
- 1,000 次/天（仍 20 RPM）
- 付费模型 RPS = 账户余额美元数（最低 1，最高 500）

**对 Agent 工作流的实际影响:**
- 50 次/天对 agent 开发测试完全不够 — 一个 agent 循环可能几分钟就烧完
- 20 RPM 对连续 tool calling 是硬瓶颈 — agent 一步 5 个 tool call = 用掉 25% 的分钟额度
- 免费模型可用性不稳定 — 硬编码的 fallback 模型可能一周后就下线了
- 社区测试（2026-02）确认：仅 DeepSeek Chat v3、Llama 4 Maverick、Qwen3-235b 三个免费模型在 agent tool calling 中表现可接受，其余大部分不可用

**关键问题**: 免费模型随时可能被 provider 从免费层撤下（无通知），导致硬编码的模型 ID 静默失败。

---

### 4. 用户被意外收费的风险

**收费机制:**
- 充值采用预付 credits 制，**不可退款**
- Credits 365 天后过期（余额丢失）
- 充值时收取 5.5% 手续费（信用卡）/ 5.0%（加密货币），最低 $0.80/笔
- 账户余额耗尽后，付费模型请求返回 402 错误（不会自动扣费产生负债）

**意外收费案例:**
- OpenClaw（Claude Code 等工具）曾因未正确发送 OpenRouter attribution headers，导致本应免费的请求被当作付费请求计费（GitHub issue #57498，已修复但说明了集成层面的收费陷阱）
- 付费模型的 RPS 与余额挂钩 — 余额耗尽意味着并发能力骤降，可能触发生产环境问题

**判断**: 只用免费模型、不充值的情况下，不存在意外收费风险。但一旦充值，5.5% 手续费 + 365 天过期是确定性成本。对于 agent 工作流，免费层的 50 次/天限制意味着你大概率需要充值 $10+，这时就需要接受这些条款。

---

### 5. 数据隐私风险

**OpenRouter 层面:**
- 默认不存储 prompt/response 内容（除非用户手动开启 prompt logging）
- 但开启 prompt logging 后，ToS 中包含对 Inputs/Outputs 的**永久商业使用许可**（2025-04 ToS 更新，Skool 社区讨论引发关注）
- 请求元数据（token 数量、延迟等）始终被记录
- 数据保留策略为"as long as necessary"，删除需手动申请

**Provider 层面:**
- 免费路由（openrouter/free）会随机分配到不同 provider，每个 provider 有独立的数据政策
- 免费模型池中的 provider 会随时间变化，你的实际数据流经路径是动态的
- 部分 provider 可能用 prompt 训练模型

**对 Agent 工作流的影响**: 如果你的 agent 处理敏感数据（客户信息、商业策略、NDA 内容），免费路由模式的数据流向不确定性是一个合规风险。OpenRouter 提供了基于数据政策的路由过滤选项，但需要主动配置。

---

### 6. 稳定性和可用性

**宕机记录（2025-08 至 2026-02，8 个月内）:**
- 2025-08-28: 数据库宕机 50 分钟
- 2026-02-17: 第三方缓存依赖故障，38 分钟（20% 请求失败 -> 80-90% 失败）
- 2026-02-19: 同一缓存层再次故障，35 分钟

**关键问题**: 2026-02 宕机期间，OpenRouter 返回 401 "User not found" 错误（实际是基础设施故障），导致开发者浪费时间排查 API Key 问题。此问题已修复（现返回 503），但暴露了路由层引入额外故障模式的风险。

**延迟**: 额外 25-40ms 路由层开销，对交互式场景影响不大，对高频调用有累积影响。

**国内可访问性**: 可直连，支持支付宝/微信充值。这比大多数海外平台有优势。

---

### 7. 迁出难度

**评估**: 低

- OpenAI 兼容 API — 切换只需改 base_url 和 model name
- 无长期合同，预付制
- 但：如果你用的是 `openrouter/free` 路由（不指定具体模型），迁出时需要选定替代模型并测试

---

### 8. 综合判定

| 维度 | 评级 | 说明 |
|------|------|------|
| 平台存续 | 安全 | $1.3B 估值，顶级机构背书，8M 用户 |
| 免费层持久性 | 危险 | 已多次缩水，趋势明确：纯免费用户会被持续压缩 |
| Agent 工作流适用性 | 不推荐（免费层） | 50 次/天 + 20 RPM + 模型不稳定 = 无法用于生产 agent |
| Agent 工作流适用性 | 可用（充值 $10+） | 1,000 次/天 + 多模型切换 + OpenAI 兼容 = 开发测试够用 |
| 意外收费 | 低 | 只要不充值就不会被收费；充值后 5.5% 手续费和 365 天过期是确定成本 |
| 数据隐私 | 需注意 | 默认安全，但免费路由的数据流向不确定；ToS 有永久许可条款需警惕 |
| 稳定性 | 中 | 无 SLA，8 个月 3 次宕机；自动 failover 是加分项 |
| 迁出难度 | 低 | OpenAI 兼容，切换成本低 |

**最终结论: 需警惕**

OpenRouter 作为平台是靠谱的 — 资本、用户量、技术能力都在头部。但**免费层不适合用于 agent 工作流生产环境**，原因是：

1. **额度不够**: 50 次/天对 agent 几乎没用，$10 充值后 1,000 次/天才勉强够开发测试
2. **模型不稳定**: 免费模型随时可能下线，fallback 链一周就过期
3. **确定性缩水**: 免费层在过去一年已缩水两次，且官方明确说了会继续减少免费模型

**建议方案:**

- **开发/测试阶段**: 可以用 OpenRouter（充值 $10），利用多模型切换快速迭代
- **生产环境**: 不要依赖 OpenRouter 免费层。两个方向：
  - 方案 A: OpenRouter 付费层（需要的模型按量付费，有 RPS 保证）
  - 方案 B: 你现有的 NVIDIA NIM（免费但仅 Step 3.5 Flash 稳定）+ 硅基流动（国内直连免费开源模型）+ OpenRouter 充值 $10 作为补充
- **Agent 工作流的核心模型**: 建议用 DeepSeek V4 Pro 或 Qwen3 Coder（在 OpenRouter 上有 :free 版本且 tool calling 支持较好），但要准备好 fallback 到付费版本
